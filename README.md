# Reminder app in C

Reminder app that sends a system and sound notification at specified time.

Instalation: get the binary from releases and put it in your .local/bin/  
Usage: reminder time message silent  
Example: reminder 12:00 "Buy me a coffee!: https://ko-fi.com/helenana" true    

Arguments:  
time - Required. must be formatted as HH:MM.  
message - Dictates notification message, in case of multi-word must be encased in double quotes.  
silent - Disables notification sound.
